常见安装与配置问题排查

安装后如果在命令行输入 python 提示找不到命令，通常是 PATH 环境变量未配置。Windows 用户可以在安装时勾选 Add Python to PATH，或手动添加安装目录到系统变量。

macOS 和 Linux 系统可能自带 Python 2，直接输入 python 可能指向旧版本。此时应使用 python3 命令，或通过 alias 将 python 指向 python3。

pip 安装包速度慢时，可以配置国内镜像源，如清华 TUNA 或阿里云镜像。使用 pip config set global.index-url 命令即可永久更换源。

如果遇到权限错误，不要盲目使用 sudo pip install，建议在虚拟环境中安装，或使用 pip install --user 安装到用户目录。

  • 命令未找到：检查 PATH 环境变量
  • 版本混淆：使用 python3 明确调用
  • 下载慢：配置国内 pip 镜像源
  • 权限错误：使用虚拟环境或 --user

实用问答

Python91官网入口是官方网站吗？

不是。Python 的官方网站是 python.org，由 Python 软件基金会维护。Python91官网入口通常是第三方导航页或搜索词，用于引导用户找到官方资源。请务必以 python.org 为准，避免在非官方页面下载安装包。

如何安全下载 Python 安装包？

建议直接访问 python.org 的下载页面，选择与你的操作系统匹配的安装包。下载后可以核对官方提供的 MD5 或 SHA256 校验值。避免从不明来源的网盘或下载站获取安装包，以防捆绑恶意软件。

Python 2 和 Python 3 应该选哪个？

除非你维护的是旧项目且无法迁移，否则应选择 Python 3。Python 2 已于 2020 年停止维护，不再接收安全更新，且大量现代库已不再支持 Python 2。新项目一律推荐使用 Python 3 的最新稳定版。

安装 Python 后命令行提示找不到怎么办？

这通常是 PATH 环境变量未配置导致的。Windows 用户可以在安装时勾选 Add Python to PATH，或手动将 Python 安装目录及 Scripts 子目录添加到系统环境变量。macOS 和 Linux 用户可尝试使用 python3 命令，或检查 shell 配置文件中的 PATH 设置。

Python 官方文档有中文版吗？

Python 官方文档以英文为主，但部分版本提供中文翻译，可在 docs.python.org 的语言选择中查看。中文翻译可能滞后于英文原版，建议以英文文档为准，中文资源可作为辅助理解。

如何配置 pip 国内镜像源加速下载？

可以运行 pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple 来设置清华镜像源。也可以临时使用 pip install -i 镜像地址 包名 的方式。设置后 pip 会从国内镜像下载，速度通常有明显提升。

学习 Python 需要安装哪些额外工具？

基础学习只需要 Python 解释器和一个代码编辑器，如 VS Code。进阶可根据方向选择：数据分析可安装 Jupyter Notebook 和 Anaconda，Web 开发可安装 Django 或 Flask，版本控制建议学习 Git。虚拟环境工具 venv 或 conda 也推荐尽早掌握。
